# 福祉用具ユーザー辞書（Google日本語入力用）

福祉用具貸与の計画書・記録で使う定型文（選定理由・提案理由・留意事項・ケアマネージャーとの相談記録・モニタリング・相談内容）を、
Google日本語入力のユーザー辞書として登録できる形にまとめたものです。

## 一覧ページ（ブラウザで開くだけで使えます）

公開ページ：https://akamar08taiyo-bot.github.io/fukushi-jisho/

- 文やよみで検索でき、分類ごとに一覧で見られます。
- 文例・よみ・分類・小分類は、クリックしてその場で書き換えられます。書き換えたあと枠の外をクリックすると、そのまま保存されます（Escキーで取り消し）。
- 単語の追加と削除ができます（削除した文は「削除済み」から元に戻せます）。
- 「テキストファイルに変換」で Google日本語入力の取り込み用ファイルを、「Excelファイルに変換（分野別）」で分野ごとにシートを分けたExcelを作れます。

書き換え・追加・削除した内容は、使っているパソコンのブラウザに保存されます（人ごと・パソコンごとに別々です。ブラウザのデータを消すと元に戻ります）。
ページの本体は `site/index.html` で、このファイルをダウンロードして開いても同じように使えます。

| ファイル | 内容 |

## 個人情報について

このリポジトリは公開されているため、人名・住所・メールアドレス・社内関係者名など個人情報を含む登録（69件）は入れていません（877件。取り込み用TXTは、タブレット用の一式15件を除いた862件）。

## 追加した文

元の辞書を整理したうえで、次の文を新しく追加しています（Excelの「辞書一覧」の備考欄に「追加」と表示）。

- 選定理由：各用具10件以上になるように追加
- 提案理由：各用具10件
- 留意事項：各用具に3件ずつ
- ケアマネージャーとの相談記録（担当者会議）：新規・中間見直し・更新・福祉用具追加・サービス内容変更・ケアプラン長期切れの各種類に3件ずつ
- モニタリング：利用目標・点検結果・身体状況・意欲・家族・サービス利用・住環境・総合評価・今後の方針などの各記入欄が10件になるように追加（総合評価は、今後の方針まで含めた文を中心に10件）
- モニタリング（タブレットの「利用者などの変化」の欄に合わせた構成）：身体状況・ADL／意欲・意向等／家族の状況／サービス利用等・住環境／福祉用具サービス計画の見直し。福祉用具サービス計画の見直しには、評価・点検・今後の方針（てきぎ）を組み合わせた一式の文を15件（よみ：ひょうか）
- 相談内容（ご本人の言葉）：3件
- 商品名：2件（ゆくえあ → シャワーチェア（Air）ミドルSPワンタッチ、ゆくこん → シャワーチェア（Air）コンパクトSPワンタッチ）

## 取り込み方（Google日本語入力）

1. タスクバーの「あ」（または「A」）を右クリック →「辞書ツール」を開く
2. 念のため、今の辞書を「管理」→「選択した辞書をエクスポート」でバックアップする
3. 「管理」→「新規辞書にインポート」→ `.txt` を選び、辞書名を入れて「インポート」
4. 古い辞書（統合前のもの）は「管理」→「選択した辞書を削除」で削除する（残すと候補が二重に出ます）

## よみのルール

| 種類 | よみ | 例 |
| --- | --- | --- |
| 選定理由 | 用具名＋「せ」 | てすりせ／しゃわーちぇあせ／べっどせ |
| 提案理由 | 用具名＋「ていあん」 | てすりていあん／くるまいすていあん／べっどていあん |
| 留意事項 | 用具名＋「りゅ」 | てすりりゅ／しゃわーちぇありゅ／べっどりゅ（福祉用具全般の共通の文は りゅうい） |
| ケアマネージャーとの相談記録 | 種類＋「たんかい」 | しんきたんかい／ちゅうかんたんかい／こうしんたんかい／ついかたんかい／へんこうたんかい／ちょうきたんかい |
| モニタリング | 記入欄ごと | りもく（利用目標）／てんけん（点検結果）／しなし（身体状況・ADL）／いなし（意欲・意向等）／かなし（家族の状況）／さなし・じゅうかんきょう（サービス利用等・住環境）／ひょうか（福祉用具サービス計画の見直しの一式、短い総合評価）／てきぎ（今後の方針）／こんけい／しんきのうひん／ついかのうひん |
| 相談内容 | そうだんきろく | ご本人の言葉 |

事業所名・定型文などのよみは統合前と同じです。使わなくなった旧よみと新しいよみの対応は、Excelの「よみ早見表」にあります。

## 文章のルール（誰から誰への文章か）

- **選定理由**：担当者（福祉用具専門相談員）が、ご本人・ご家族・ケアマネジャーに選定の理由を説明する文。「〜のため、〇〇を選定しました。」にそろえています。
- **提案理由**：担当者が、用具や手すりの設置を提案した理由を説明する文。選定理由とは分けて、「〜のため、〇〇を提案しました。」の形にしています。
- **留意事項**：用具の点検（ロックピン・ゴムの摩耗・固定の緩みなど）はモニタリング時に担当者が行います。ご本人・ご家族にお願いするのは「使うときの注意」と「ぐらつき等の異常を感じたら担当者へ連絡」です。すべての文の先頭に（手すり）（シャワーチェア）（床ずれ防止用具）のように用具名を付けています（福祉用具全般の共通の文には付けていません）。
- **ケアマネージャーとの相談記録・モニタリング**：担当者が記録・報告する文（です・ます調）。「更新担当者会議。〜」で始まる短い文は、である調のメモ用です。
- **相談内容**：ご本人が担当者に話した言葉として、へりくだり過ぎない自然な話し言葉にしています。

## 100文字のルール

Google日本語入力は1語あたり最大300バイト（全角100文字）までです。すべての登録を100文字以内にしています。
ただし、モニタリングの「福祉用具サービス計画の見直し」（よみ：ひょうか）の一式は、タブレットで登録するため文字数の制限を設けていません（Excelの判定は「制限なし」。Google日本語入力には登録できないため、取り込み用TXTには入れていません）。
Excelの「文字数」「判定」列は自動計算なので、文章を書き換えたときも100文字を超えていないか確認できます。

## 公開のしかた

公開ページは `gh-pages` の枝に置いた `index.html` を表示しています（Settings → Pages の Source は「Deploy from a branch」の gh-pages）。
main の `site/` を書き換えて push すると、`.github/workflows/pages.yml` が同じ中身を `gh-pages` に置き、数分で公開ページが新しくなります。
